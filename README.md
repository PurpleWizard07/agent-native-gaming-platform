# Agent-Native Gaming Platform

A gaming platform designed for both humans and agents. Players can describe
the gaming experience they want, and a WebMCP-enabled agent can operate the
platform to turn that intent into a playable session.

Built for the WebMCP Challenge hackathon. Design doc:
[webmcp-gaming-platform-concept.md](./webmcp-gaming-platform-concept.md).
Build plan: [implementation-plan.md](./implementation-plan.md).

> This is a fictional gaming platform inspired by familiar digital game-store
> and social-gaming workflows. All users, libraries and friend data are
> synthetic; no real game is launched. The project demonstrates how such a
> platform can be made agent-operable through WebMCP.

## Status

Work in progress — see [implementation-plan.md](./implementation-plan.md) for
current phase.
